# Changelog

All notable MAD CMS changes are documented here.

## 0.1.0-rc.2 - 2026-08-17

- Added Laravel 13 compatibility across all required Illuminate components.
- Expanded source and distribution-archive CI to verify clean Laravel 13 installations.
- Added Packagist-only installation verification for tagged releases.

## 0.1.0-rc.1 - 2026-08-05

- Added reusable Laravel 11 and 12 CMS models, migrations, registries, queries, persistence services, publishing policy, form processing, and administration controllers.
- Added opt-in page, module, form, submission, category, registry, and public-form routes.
- Added the React rows/columns page builder, 22 core renderers, reusable modules, guided content and design fields, responsive controls, scoped CSS, and form rendering.
- Added standalone Inertia collections and create/edit screens for pages, reusable modules, and forms.
- Added standalone category management and form-submission detail/status workflows.
- Added safe hybrid mode so the production MAD Tech Services website can adopt package services without replacing existing routes, content, or presentation.
- Added Laravel 11/12 clean-install CI, frontend contract checks, and guarded GitHub tag releases.
